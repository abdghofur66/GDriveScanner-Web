Keamanan & Privasi Terjamin

Proses pemindaian dilakukan langsung di browser Anda. Tidak ada data, nama folder, atau tautan yang kami simpan. Pembuat web tidak melihat aktifitas Anda.

Petunjuk Akses Folder Publik

Pastikan folder yanga akan Anda pindai, memiliki hak akses terbuka (Publik) atau "Siapa saja yang memiliki link" (Anyone with the link)

Otomatis Ekstrak Link

Anda tidak perlu lagi mencari ID secara manual. Cukup salin URL lengkap folder Drive Anda dan tempel (paste) ke kolom pencarian di bawah.

ID Berhasil Diekstrak
